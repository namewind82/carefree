# SleekMusic

Typecho 音乐插件，为 Sleek 说说主题提供全站固定播放器、`[music]` 短代码播放器和网易云音乐卡片。

## 功能

- 全站左上角固定播放器：首页、文章页、标签页、相册页等都会显示
- 自动读取最新一篇包含 `[music]` 的已发布文章
- 没有正在播放的曲目时，默认停在该最新音乐上
- 切换页面后恢复上次播放的曲目、进度和播放状态
- 文章/页面内 `[music]` 短代码播放器
- 原生 HTML5 Audio，无第三方依赖
- 同页多个播放器自动互斥
- 播放器支持播放/暂停、进度拖动、收起/关闭
- 移动端自适应，深色模式适配

## 安装

1. 上传 `SleekMusic` 文件夹到 `usr/plugins/SleekMusic`
2. 后台 → 控制台 → 插件 → 启用 **SleekMusic**
3. 后台 → 控制台 → 插件 → SleekMusic → 设置

## 设置

- **音乐地址**：mp3 地址，作为没有最新音乐文章时的兜底
- **歌曲标题**
- **歌手**
- **封面地址**：留空使用内置封面
- **全站固定播放器**：显示 / 不显示

## 短代码

```text
[music url="https://example.com/song.mp3" title="情怨" artist="刘欢" cover="https://example.com/cover.jpg"]
```

- `url` 必填
- `title`、`artist`、`cover` 可省略
- 支持文章、页面、说说正文
- 同一页面多个播放器时只播放一个

## 播放状态

当前曲目、封面、播放进度和播放状态会写入 `localStorage`（键名 `sleek-music-now`）。

- 切换页面后，播放器会恢复曲目和进度并尝试继续播放
- 如果浏览器阻止自动播放，首次点击/按键页面时会恢复播放
- 暂停或关闭播放器后重新访问，会回到最新音乐，而不是旧曲目

## 说明

- 浏览器可能限制自动播放；首次交互后播放最稳定
- 插件不修改数据库结构
- 停用后播放器不再输出
